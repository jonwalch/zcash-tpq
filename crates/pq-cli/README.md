# Experimental SLH wallet CLI

Default-off SLH-only Regtest commands, reusing the pinned Transparent PQ wallet's
command flows and private-terminal password handling. See the maintained
[command guide](../../docs/slh-dsa-b128s/cli.md),
[wallet contract](../../docs/slh-dsa-b128s/wallet.md) and
[source mappings](../pq-wallet/CLI_RPC_PROVENANCE.json).

Enable `experimental-slh-dsa-b128s` for wallet operations. Default normal/build
dependencies are empty. Human live and terminal validation remains separate from
focused parser and scripted loopback tests.
