## Added

- Added optional experimental SLH-DSA-B-128s support for isolated custom testnets,
  with explicit activation and check limits, chain-specific state, backups, peer caches,
  automatic node identity keys, and native handshake identity,
  local genesis generation, and effective-rule diagnostics in `getblockchaininfo`
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).

## Fixed

- Preserved custom-testnet unshielded coinbase and disabled Orchard soft-fork
  settings when saving and loading TOML. Rejected aliases of known public
  bootstrap hosts, native peer identities, and IP addresses on SLH devnets,
  including ambiguous numeric IPv4 forms, whitespace, IPv4-compatible IPv6 aliases,
  and the standard NAT64 prefix. Warned when upgrading from a name-only identity
  key requires new bootstrap peer IDs. Required native peering for SLH custom
  testnets to prevent legacy fallback between different rules, and rejected
  malformed native bootstrap entries before startup
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).
- Rejected overflowing seed counts and activation heights before generating
  keys or blocks in the shared ordinary and SLH custom-testnet genesis helper
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).
- Included fresh native connections in peer diagnostics, RPC connection counts,
  and health checks. Preserved legacy upgrade metadata and removed disconnected
  connections from active counts
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).
- Bound new devnet fixture production to the current upstream source pin and
  rejected source-ledger drift before signing. Historical fixtures retain their
  original identities
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).
