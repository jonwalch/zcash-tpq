## Added

- Added optional experimental SLH-DSA-B-128s support for isolated custom testnets,
  with explicit activation and check limits, chain-specific state, backups, peer caches,
  and automatic node identity keys,
  local genesis generation, and effective-rule diagnostics in `getblockchaininfo`
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).

## Fixed

- Preserved custom-testnet unshielded coinbase and disabled Orchard soft-fork
  settings when saving and loading TOML. Rejected aliases of known public
  bootstrap hosts, native peer identities, and IP addresses on SLH devnets,
  including ambiguous numeric IPv4 forms, whitespace, IPv4-compatible IPv6 aliases,
  and the standard NAT64 prefix. Warned when upgrading from a name-only identity
  key requires new bootstrap peer IDs
  ([#11](https://github.com/jonwalch/zcash-tpq/pull/11)).
