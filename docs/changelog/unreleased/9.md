## Changed

- Raise the block limit from 2 MB to 20 MB (20,000,000 bytes) across this fork
  for devnet use. Update peer transport limits and transaction indexes to support
  larger blocks, including raw and verbose RPC responses. The state database
  format is now 30.0.0; version 29 databases require a fresh sync, and startup
  rejects older versions manually moved into the v30 directory
  ([#9](https://github.com/jonwalch/zcash-tpq/pull/9)).
